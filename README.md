# 🚀 Автозапуск проекта с Docker

Этот проект использует `Docker` и `docker-compose` для быстрой настройки и запуска. Следуйте шагам ниже, чтобы начать работу.

---

## 📦 Шаг 1: Создание `.env` файла

Скопируйте пример конфигурации окружения:

```bash
cp env.example .env
```

---

## ⚙️ Шаг 2: Заполните `.env` файл

Откройте файл `.env` и добавьте необходимые параметры конфигурации (например, токены, ключи доступа, порты и т.д.).

---

## ▶️ Шаг 3: Запуск проекта

Соберите и запустите контейнеры с помощью команды:

```bash
docker-compose up --build
```

---

## 🛠️ Шаг 4: Активируйте нужный код

После запуска всех сервисов, **раскомментируйте** код внутри контейнера `autoresponder_web`:

- Перейдите в директорию `commands` приложения.
- Откройте файлы:
  - `admin.py`
  - `models.py`
- Раскомментируйте отмеченные участки кода, чтобы активировать необходимый функционал.

---

✅ Теперь ваш проект должен быть полностью готов к работе!
